# Sparklux ヘルプ

## Sparklux は何をするアプリか

**SDR の動画を、実時間で HDR にして表示します。** ファイルを変換して別に保存するのではなく、
再生しながら画面に出す時点で処理します。あわせて解像度も拡大します。

HDR の動画（HDR10・HLG・Dolby Vision Profile 8）は**何も足さずそのまま**表示します。

## 動作条件

| | |
|---|---|
| macOS | 14 以降 |
| HDR 表示 | **HDR に対応した画面**が必要です（内蔵 XDR ディスプレイ、対応する外部ディスプレイなど）|
| 対応形式 | MP4 / MOV / M4V ／ HLS（.m3u8）／ 直リンク URL ／ ネットワーク共有 |

⚠️ HDR に対応していない画面では、変換は働きません。その場合は画面上部にその旨を表示します。

## 最初にやること — 画面のキャリブレーション（⌘K）

**これをすると、明るさが正しく出ます。**していない場合は控えめな既定値で動きます。

1. ⌘K を押す
2. **手順 1/2** — 左の白い面と右のパッチが**同じ明るさに見える**ところで Enter。
   境目が消えるところが正解です
3. **手順 2/2** — 値を上げていき、**それ以上明るくならなくなった**ところで Enter

測った値は画面ごとに記憶されます。

## 色の作り（プリセット）

操作バー右端のボタンから選びます。

| | 内容 |
|---|---|
| **変換しない** | 元のまま表示します |
| **控えめ** | 少しだけ明るく。白飛びが気になるとき |
| **シネマ** | 中間調はそのまま、光る所だけ伸ばします |
| **ナチュラル** | 自然な明るさ。破綻しにくい既定値 |
| **ビビッド** | 明るい部分の色を強く残します |
| **リアル** | 実写らしい階調（モデルを使います）|

**A/B ボタン**で 2 つのプリセットを見比べられます。

## 解像度（拡大）

同じボタンの下側で選びます。

| | 内容 |
|---|---|
| **拡大しない** | 素材の解像度のまま |
| **くっきり（MetalFX）** | 既定。素材にある情報だけを使い、輪郭を作りません |
| **くっきり（Lanczos）** | 古典的な拡大 |
| **くっきり（強め）** | より強く |

⚠️ **窓が素材より小さいと拡大は働きません**（拡大する必要がないため）。
状態行に「拡大の出番なし」と出ます。**全画面**にするか窓を広げてください。

## キーボード

| | |
|---|---|
| Space | 再生 / 一時停止 |
| ← / → | 5 秒戻す / 進む |
| ⌥⌘← / ⌥⌘→ | 前の章 / 次の章 |
| ↑ / ↓ | 音量 |
| ⌘K | 画面のキャリブレーション |
| ⌘⌃F | フルスクリーン |
| ⌘O | ファイルを開く |
| ⌘⇧L | URL を開く |

## 字幕

- 動画に埋め込まれた字幕を自動で読みます
- **外部字幕**は `movie.mp4` に対して `movie.srt` のように**同じ名前**で隣に置くと自動で読みます
  （.srt / .vtt、UTF-8・Shift_JIS・EUC・UTF-16 に対応）

## 音声

- **5.1ch / 7.1ch はそのまま出力**します
- 2ch の機器につないでいる場合は**セリフが消えないように畳んで**出力します
- Dolby Atmos の動画は、その下にある 5.1ch / 7.1ch として再生します

## URL の再生

⌘⇧L で開きます。

- **動画の直リンク**（`https://…/movie.mp4`）
- **HLS**（`https://…/index.m3u8`）
- **ネットワーク共有**のアドレス

### 配信サービス（YouTube など）

⚠️ **Sparklux 単体では再生できません。**お客様ご自身が `yt-dlp` をインストールしている場合に限り、
それを呼び出して再生します。

```
brew install yt-dlp
```

- 本アプリは yt-dlp を**同梱も自動インストールもしません**
- **Netflix・Prime Video・Disney+ などは再生できません**（保護されているため）
- **VPN を使っていると取得を拒否されることがあります**（403）。切ってお試しください
- 配信側の仕様変更で動かなくなることがあります。その場合は yt-dlp を最新にしてください

## 省電力

メニューの「省電力」で選べます。**自動**では、本体が熱くなったときや電池のときに、
処理を段階的に休ませます（モデル → シャープ → 拡大 の順。HDR 変換は最後まで残します）。
休ませたことは状態行に表示します。

## 困ったとき

| 症状 | 確認すること |
|---|---|
| **色が変わらない** | 画面が HDR に対応しているか（上部に警告が出ていないか）／プリセットが「変換しない」になっていないか |
| **拡大が効かない** | 窓が素材より小さくないか（状態行を見てください）。全画面にすると効きます |
| **明るさが不自然** | ⌘K でキャリブレーションしてください |
| **ファイルが開けない** | システム設定 →「プライバシーとセキュリティ」→「ファイルとフォルダ」で許可するか、⌘O で開き直してください |
| **URL が開けない** | URL と接続を確認してください。配信サービスは上記の制約があります |
| **音が出ない** | 音声トラックが選ばれているか（メニューの「音声トラック」）|
