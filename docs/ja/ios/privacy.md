# プライバシーポリシー — Sparklux Go（iPhone / iPad）

**最終更新: 2026-10-01**

Sparklux Go（iPhone / iPad 版・以下「本アプリ」）における情報の取り扱いについて定めます。

## 1. 収集しない情報

**本アプリは、以下を一切収集・送信しません。**

- 再生した動画の**内容**
- 動画の**ファイル名・フォルダ名・保存場所**
- **視聴履歴**
- 氏名・メールアドレス・電話番号などの**連絡先情報**
- **位置情報**
- 端末を横断して個人を追跡する**識別子**

本アプリは解析ツール（アナリティクス）・広告 SDK・クラッシュレポートの送信を、いずれも組み込んでいません。開発者のサーバーはありません。

## 2. 端末内にだけ保存される情報

以下は**お使いの iPhone / iPad の中だけ**に保存され、外部には送信されません。

| 情報 | 保存先 | 目的 |
|---|---|---|
| 登録したサーバー（表示名・ホスト名・ユーザー名・最後に開いた共有とフォルダ） | 端末内のアプリ領域 | 次回すぐに接続するため |
| SMB・WebDAV の**パスワード** | **端末のキーチェーン**（この端末だけ・iCloud キーチェーンに同期しない） | 次回すぐに接続するため。保存しない選択もできます |
| Jellyfin の**ログイン後のトークン**（パスワードは保存しません） | **端末のキーチェーン**（この端末だけ） | 次回すぐに接続するため |
| 追加した「ファイル」アプリのフォルダへの参照 | 端末内のアプリ領域 | 次回も同じフォルダを開くため |
| 続きから再生する位置・視聴済みの印（合わせて最大 1000 件） | 端末内のアプリ領域 | 続きから再生する・視聴済みを示すため |
| お気に入り | 端末内のアプリ領域 | ホームの一覧に出すため |
| サムネイル（動画の縮小画像） | 端末内のキャッシュ | 一覧にすばやく表示するため |
| 字幕・小窓（ピクチャ・イン・ピクチャ）・並べ替え・表示の設定 | 端末内のアプリ領域 | 設定を保つため |
| 写真ライブラリから選んだ動画の一時コピー（最大 20 本・合計 10GB まで） | 端末内のアプリ領域（バックアップの対象外。古いものから自動で消えます） | 再生するため |

これらは本アプリを削除すると消えます（キーチェーンの項目は OS の仕様により残る場合があります）。

## 3. 写真ライブラリ

写真ライブラリの動画は、**お客様が選んだ 1 本だけ**を読み込みます。本アプリは写真ライブラリ全体へのアクセス許可を求めません。

## 4. 通信の範囲

本アプリが接続するのは、**お客様ご自身が登録したサーバー**（SMB・WebDAV・Jellyfin・DLNA/UPnP）と、**お客様が入力した URL** だけです。開発者のサーバーへの送信はありません。

- 家の中のサーバーだけでなく、家の外にあるサーバーにも HTTPS でつなぐことができます（WebDAV・Jellyfin・URL）
- 暗号化されない通信: SMB（暗号化を必須にしていないサーバーに接続した場合）、http の WebDAV・Jellyfin・DLNA/UPnP、http の URL。いずれも通信の中身が暗号化されないだけで、送信先は変わりません
- ローカルネットワークへのアクセスは、同じ Wi-Fi にあるこれらのサーバーを見つけて開くために使います

## 5. 購入情報

購入・無料体験の処理は **Apple（App Store）** が行います。本アプリはクレジットカード番号などの決済情報を受け取らず、保存もしません。

- 無料体験（3 日間）は、App Store の価格 0 円の項目として扱われ、**開始日は Apple が記録します**
- 購入済みかどうか・無料体験の期間は、Apple が発行する取引記録にもとづいて端末内で判定します
- 自動で課金されることはありません

## 6. ネットワーク通信

本アプリが通信するのは、次の場合に限られます。

| 通信 | 内容 | 送信先 |
|---|---|---|
| 共有フォルダを開く・再生する | ログインと、動画の読み取り | お客様が登録したサーバー（SMB・WebDAV・Jellyfin・DLNA/UPnP） |
| URL を開く | お客様が入力した URL への取得要求 | お客様が指定した先 |
| 購入・無料体験・復元 | 取引の処理と検証 | Apple |

## 7. 子どものプライバシー

本アプリは 13 歳未満の子どもから意図的に情報を収集することはありません（そもそも、どなたからも個人情報を収集しません）。

## 8. 変更

本ポリシーを変更する場合は、このページを更新し、上部の「最終更新」を改めます。重要な変更がある場合は、アプリの更新情報でもお知らせします。
