# Synology の NAS の動画を見る（Sparklux Go）

Synology の DSM 7.2.2 では Video Station の提供が終わりました。SMB の共有を使えば、NAS の動画をそのまま iPhone・iPad で開けます。

## 1. NAS で SMB をオンにする

1. DSM の「コントロールパネル」→「ファイルサービス」→「SMB」タブを開きます。
2. 「SMB サービスを有効にする」にチェックを入れて適用します。
3. 動画のあるフォルダ（たとえば `video`）が共有フォルダになっていて、見るユーザーに読み取り権限があるか、「共有フォルダ」で確認します。

## 2. アプリでサーバを追加する

1. iPhone と NAS を同じ Wi-Fi につなぎます。
2. Sparklux Go のホームで「サーバを追加」を開き、種類は SMB を選びます。
3. NAS の名前（例 `diskstation.local`）か IP アドレスを入れ、DSM のユーザー名とパスワードを入力します。

## 3. タップして再生

共有フォルダをたどって動画をタップします。MKV・MP4・MOV・AVI をそのまま再生でき、字幕と複数の音声も切り替えられます。

## つながらないとき

| 症状 | 確認すること |
|---|---|
| 名前で見つからない | IP アドレスで入れてみる。同じ Wi-Fi か確認する |
| 認証に失敗する | DSM のユーザー名とパスワード、そのユーザーの共有フォルダへの権限 |
| 「SMB3 の暗号化が必須」にしている | 現在つながりません。その共有だけ設定を外すか、別の共有を使ってください |
| 外出先から見たい | 自宅のネットワークにつなげる必要があります（VPN など）。アプリ側に外部サーバ経由の仕組みはありません |

その他の使い方は [Sparklux Go のヘルプ](help.md) を見てください。
